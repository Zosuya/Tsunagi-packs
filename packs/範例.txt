# description: 四種條目各寫幾條，複製這個檔改成自己的
# updated: 2026-09-16
#
# 這個包本身也能用——勾起來就打得出下面這些詞。
#
# 【格式】一行一條，欄位之間是 Tab（打空白整行會被忽略）。
# 檔頭要放在所有詞之前，遇到第一行資料就結束。

# ── 中文：第二欄是注音符號，一聲不標 ──
zh	ㄊㄨㄥㄧˋ	通譯
zh	ㄅㄛㄌㄧˊㄒㄧㄣ	玻璃心

# 字數跟音節數對不上時自動走「長輸出」，兩個音節出一長串。
# 不必特別標記，引擎自己分流。
zh	ㄗㄠˇㄢ	早安您好，今天過得如何？

# ── 日文：第二欄是平假名讀音，不是羅馬字也不是漢字 ──
ja	つなぎ	通譯
ja	にほんご	日本語

# 讀音跟表記一樣時，第三欄**還是要寫滿**——省了整條會消失。
ja	すごい	すごい

# 片假名的長音在讀音裡寫 ー。
ja	こーひー	コーヒー

# ── 英文：第三欄可以省略 ──
#
# 英文那半不只影響選字：引擎認得之後才不會把 api 拆成奇怪的碎片、
# 或誤判成日文。常打的詞收進來就對了。
en	api
en	webhook
en	kubernetes

# ── 符號：打 \名字\ 叫出來 ──
#
# 名字可以用逗號列好幾個，中日英三種都叫得出同一組。
# 第三欄的符號之間**用空白分隔**。
sym	愛心,こころ,heart	♥ ♡ ❤ 💕
sym	骰子,さいころ,dice	⚀ ⚁ ⚂ ⚃ ⚄ ⚅

# emoji 也可以。多字元的（膚色、ZWJ 組合）一定要用空白分隔，
# 不然會被拆成看不懂的東西。
sym	貓,ねこ,cat	🐱 🐈 😺 😻
