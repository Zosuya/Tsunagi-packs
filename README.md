# 通譯-Tsunagi 輸入法擴充包

[通譯輸入法](https://github.com/Zosuya/Tsunagi-IME)的擴充包。

擴充包是**獨立的一層**，補的是「詞庫收不到、但你天天打」的詞——
專業術語、遊戲名詞、公司內部的說法、自己的暱稱。一個包就是一個
`.txt`，隨時可以勾掉。

## 怎麼用

1. 下載你要的 `.txt`
2. 丟進 `%APPDATA%\tsunagi-ime\packs\`（macOS 是
   `~/Library/Application Support/tsunagi-ime/packs/`）
3. 設定頁 →「擴充包」分頁 → 重新整理 → 勾起來

**不必重開輸入法，也不必重開正在打字的程式。**

## 怎麼寫一個包

一行一條，**欄位之間是 Tab**（打空白整行會被忽略）：

```
語言	輸入	輸出
```

檔頭用 `#` 寫資訊，**要放在所有詞之前**：

```
# name: 我的包
# version: 1.0
# license: CC0
# updated: 2026-09-16
```

`# name:` 之外都可以省略。名稱沒填就顯示檔名。

### 四種條目

| 語言 | 第二欄寫什麼 | 第三欄 | 例子 |
|---|---|---|---|
| `zh` | **注音符號**（一聲不標） | 中文詞 | `zh	ㄏㄨˊㄊㄠˊ	胡桃` |
| `ja` | **平假名讀音** | 日文（漢字、片假名都行） | `ja	うさだぺこら	兎田ぺこら` |
| `en` | 英文字母串 | 可省略 | `en	api` |
| `sym` | 符號的名字 | 一組符號，**空白分隔** | `sym	星,hoshi,star	★ ☆ ✦` |

打 `\名字\` 叫出符號。名字可以用逗號列好幾個，中日英三種都叫得出來。

### 五個會讓整條靜靜消失的地方

這幾種錯**不會有任何提示**，檔案打開來都正常，就是打不出來：

- **欄位之間一定是 Tab**，不是空白
- **`ja`／`zh`／`sym` 的第三欄不能省**，就算跟第二欄一樣也要寫滿
  （`ja	すごい	すごい`）
- **`ja` 的鍵是平假名**，不是羅馬字也不是漢字。而且要是**打得出來**
  的讀音——長音寫 `ー`、中黑點 `・` 不能出現在鍵裡（只能放第三欄）
- **`zh` 的鍵是注音符號**，不是鍵盤按鍵
- **存檔要 UTF-8**。記事本選「ANSI」（Big5）整包不會載入

最省事的作法是**用設定頁的擴充包編輯器**——它直接打字就好，語言自己
判斷、讀音自己反查，上面這些坑它都會擋。

### 兩個好用的性質

**中文可以「兩個注音出一長串」**：字數跟音節數對不上時自動走長輸出，
不用特別標記。

```
zh	ㄍㄨㄥㄙㄏㄤˋㄏㄠˋ	台北市信義區信義路五段 7 號
```

**英文那半不只影響選字**：引擎認得之後才不會把 `api` 拆成奇怪的碎片、
或誤判成日文。所以就算不為了選字，把常打的英文詞收進來也有用。

## 授權

**沒特別註明的包視為 CC0**（放棄著作權，隨便用）。詞表是資料不是軟體，
CC0 最適合流通。

要用別的授權就在檔頭寫清楚：

```
# license: CC BY-SA 4.0
```

**ND 與 NC 的資料不收**。理由不是意識形態，是那兩種會讓「這個包能不能
再散布」變成逐案判斷，而包的價值就在流通。

## 投稿

開 PR 就好。**真正要講清楚的是來源**，不是授權——來源清楚了授權自然
就定了。

- 自己整理的 → 預設 CC0，不用多寫什麼
- 從別處來的 → 在 PR 裡說明出處，並在檔頭 `# license:` 標上原本的授權

一個包一個主題，檔名就是它在設定頁顯示的名字。
